

CLI Agent – Prompt Engineering

תיאור הפרויקט:
הפרויקט CLI Agent ממיר הוראות בשפה טבעית לפקודות Windows CMD באמצעות מודל שפה מקומי.

המשתמשת כותבת הוראה בעברית או באנגלית, והמערכת מחזירה פקודת CMD מתאימה.

טכנולוגיות:
- Python
- Gradio – ממשק משתמש
- Ollama – הרצת מודל שפה מקומי
- Qwen 2.5:3B – מודל השפה

מבנה הפרויקט:
- main.py – הגרסה הסופית של המערכת.
- main_v1.py – גרסת הפרומפט הראשונה.
- main_v2.py – גרסת הפרומפט השנייה.
- main_v3.py – גרסת הפרומפט השלישית.

תהליך השיפור:
במהלך הפרויקט נבדקו שלוש גרסאות של פרומפט באמצעות תרחישי בדיקה זהים.

הגרסה הראשונה כללה הנחיות בסיסיות, הגרסה השנייה הרחיבה את ההנחיות להבנת הבקשות, והגרסה השלישית כללה כללים מפורטים יותר בנושא דיוק ובטיחות.

תוצאות:
V1 – דיוק של 58.8%
V2 – דיוק של 64.7%
V3 – דיוק של 52.9%

בבדיקות שנערכו, גרסה V2 השיגה את אחוז הדיוק הגבוה ביותר.

הפעלת הפרויקט:
יש להתקין Python, Ollama ואת המודל Qwen 2.5:3B.

להפעלת המערכת יש להריץ:
python main.py

הממשק נפתח בדפדפן באמצעות Gradio.

מסקנות:
הניסויים הראו כי ניסוח מפורט יותר של הפרומפט אינו מבטיח שיפור בתוצאות. חשוב לבדוק את השפעתם של השינויים באמצעות תרחישי בדיקה קבועים ולהעריך את הדיוק והבטיחות בנפרד.
